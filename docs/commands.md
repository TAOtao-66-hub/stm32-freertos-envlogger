# 串口与电脑工具

USART1：115200、8N1、无流控。使用小写命令；支持 CR/LF 行尾，也支持约 100ms 无新输入后结束命令。完整语法以固件返回的 help 为准。

```text
help
get
diag
save
log cancel
```

查看阈值、分页历史和设置语法请先发送 help。电脑校时和 CSV 导出建议直接使用 Tools 下的脚本。

导出只涵盖开始时已提交的记录快照。导出期间隔离 ENV 文本和普通命令，普通命令需要结束后重新发送；取消不会停止正常历史生成。若导出所需旧数据被环形覆盖，会报告失败。

历史清空需要依次发送 log clear 和 log clear confirm，间隔不超过 10 秒。该操作会持久化清空可查询的旧历史，使用前自行保留需要的数据；正常清空保留报警参数与当前校时。这里的清空是逻辑清空，物理旧字节随之后的环形覆盖回收。
